# 屏幕亮度保持（KeepAwake）

一个轻量的 Windows 桌面小工具，用于**阻止屏幕熄灭与系统休眠**。适合在查看长文档、挂机下载、在线演示、远程值守等场景下，让电脑屏幕保持常亮、系统不自动睡眠。

## 功能特点

- 通过调用 Windows 系统 API `kernel32.dll` 的 `SetThreadExecutionState`（标志 `ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED`）持续保持屏幕与系统的唤醒状态。
- 可设定保持时长，范围 **1 ~ 1440 分钟**（最长 24 小时）。
- 界面实时显示运行状态与倒计时（时分秒格式）。
- 到达设定时长后自动停止；也可随时手动停止。
- 单文件绿色程序，无需安装、无需管理员权限。

## 使用方法

1. 双击 `KeepAwake.exe` 运行。
2. 在时长下拉框中选择预设时长，或在自定义输入框中填写 **1 ~ 1440** 之间的分钟数。
3. 点击开始按钮，程序即开始保持唤醒，界面倒计时随之开始。
4. 需要提前结束时，再次点击按钮停止即可；到达设定时间后程序会自动停止保持。
5. 直接关闭程序窗口也会停止保持并退出。

## 运行环境

- 操作系统：Windows（依赖 Win32 API 与 .NET Framework / WinForms 运行时，Windows 系统通常已自带）。
- 无需额外安装第三方库，单文件即可运行。

## 注意事项

- 本工具只是阻止系统**自动**息屏与休眠，不影响手动锁屏（Win+L）或手动关闭显示器。
- 保持唤醒期间电脑正常耗电，无需使用时请及时停止。
